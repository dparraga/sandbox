# Implementation

Before role work, load [avoid-overengineering](../.agents/skills/avoid-overengineering/SKILL.md) and [requested-scope-only](../.agents/skills/requested-scope-only/SKILL.md).

- **Inputs:** explicitly approved feature/design, acceptance criteria, test plan, review/PR findings.
- **Responsibilities:** implement only approved scope; correct defects and review findings; coordinate interfaces with Testing and Documentation.
- **Outputs:** focused changes, actual local validation evidence and own local handoff.
- **Handoffs:** runnable increments to Testing promptly; behavior/setup changes to Documentation; completed changes to Review through Lead. Correct PR feedback on the same branch.
- **Limits:** implement only the currently approved feature; no new requirements, unapproved dependencies/design, merge or fabricated results. Follow AGENTS.md and save own handoff at milestones/pauses.

Before creating or modifying documentation, load [project-documentation](../.agents/skills/project-documentation/SKILL.md).
